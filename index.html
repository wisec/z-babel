Quick start

        
    
          
  • Open a local Z-machine story, or use the bundled default story.
    • 
          
  • Choose the target language and add a Gemini API key in Settings.
    • 
          
  • Type commands in the input box and press Send.
    • 
          
  • Use the up and down arrow keys to browse command history.
    • 
          
  • Click Speak, or hold the left Shift key while speaking, for voice input.
    • 
          
  • Save, restore, export, or import browser saves from the toolbar.
    • 
          
  • Use the map and inventory panels to track explored rooms and carried items.
    •
